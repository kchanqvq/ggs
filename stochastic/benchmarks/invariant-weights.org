#+TITLE: Cost-invariant stochastic rewrite weights

* Change
For a supported pure additive integer analysis, compilation can prove that a
rewrite preserves proxy cost. Such a rule now uses =fastexp2(0)= directly instead
of repeatedly evaluating RHS cost, subtracting, and computing the exponential in
both finalization and finite-temperature sampling. The approximate exponential
at zero is preserved exactly; it is not replaced with =1.0=.

For example, reassociation under node-count cost gives the same expression on
both sides: =min(B, 2 + cost(a) + cost(b) + cost(c))=. This repeats across the
ancestors rebuilt after each rewrite, so eliminating it reduces substantial work.

[[file:../cost-model.lisp][The proof]] recognizes constructor-independent clauses with distinct variables,
nonnegative integer constants and sums of child analysis values, merged with MIN
against a nonnegative integer bound. Repeated child contributions are supported.
Nested clamps can be flattened because all terms are nonnegative and nonzero
coefficients are positive integers. Variable multiplicities and constant terms
must agree. Missing arities, saturation and zero-argument variable-head templates
are handled explicitly. No user code is evaluated by the proof.

Only unconditional single rewrites are specialized. Arbitrary guards, =:eval=
bodies, floating analyses, sequence splices, and unsupported analyses retain the
original calculation. Recognition is based on definitions, not benchmark or
analysis names. Matching, rewrite order, allocation, random sampling and floating
accumulation order are unchanged. The internal compiler keyword
=:optimize-invariant-weights nil= exists for differential tests and ablation;
normal compilation enables the proof without a runtime branch.

* Validation
The isolated change passes all 5,997 stochastic checks. New tests compare full
accepted-move histories with the proof off/on for multiple seeds, hard-walk and
finite-temperature steps, separate proxy cost, mutable guards/bodies, and fallback
analyses. Another 300 cases compare every node's weight bits, rewrite counts and
analysis metadata, including saturated costs, repeated child contributions and
several beta constants. The new test component replaces the stale reference to
=stochastic/tests/redefinition.lisp=, which is absent in the base revision.

* Benchmark protocol
Measured on the original vector backend, from base revision
=055c5834ca9a5f46435bc151d8650be07c391f4b= with only this compiler change, its tests,
and benchmark files. SBCL 2.6.2, AMD Ryzen Threadripper PRO 7985WX, logical CPU 24.
All performance runs are serialized.

The [[file:invariant-weights.lisp][harness]] alternates proof OFF/ON within a process for six paired seeds.
Compilation and warm-up happen before measurement, and full host GC is outside
each interval. Each sample checks that its precompiled cache is used; every pair
must agree on final cost, term, accepted moves and restarts. Timing includes host
GC during the search. Tables show wall-time medians; speedup is OFF/ON.

The main run uses one million rewrites and seeds 0–5. The holdout doubles the
length to two million rewrites with new seeds 10–15. =powers-64= uses the
unsupported =weighted= analysis as a negative control. Four cases exercise the
same reassociation rules at different sizes/leaf types; the results are not a
claim about arbitrary rule sets or user Lisp analyses.

* Reproduction
Make the repository and its existing dependencies, including =lp-hash-table=,
available through ASDF/Quicklisp. Run from the repository root:
#+begin_src sh
sbcl --non-interactive --eval '(require :asdf)' \
  --eval '(asdf:load-asd (truename "ggs.asd"))' \
  --eval '(ql:quickload :ggs/stochastic/tests :silent t)' \
  --eval '(unless (fiveam:run! :ggs/stochastic) (uiop:quit 1))'

WEIGHT_STEPS=1000000 WEIGHT_ROUNDS=6 taskset -c 24 \
  sbcl --non-interactive --load stochastic/benchmarks/invariant-weights.lisp
WEIGHT_STEPS=2000000 WEIGHT_ROUNDS=6 WEIGHT_SEED_START=10 taskset -c 24 \
  sbcl --non-interactive --load stochastic/benchmarks/invariant-weights.lisp
#+end_src
Choose an available logical CPU on other machines. Raw samples are included below.
