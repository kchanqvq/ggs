#+TITLE: GGS: Rewrite-based Optimizations
* Example
Define a simple problem:
#+BEGIN_SRC lisp
  (in-package :ggs-user)

  ;; A ruleset is a named list of (LHS RHS [:guard CONDITION]) clauses.
  ;; ?x are pattern variables.
  (defrw* cancel
    ((+ (- ?a) ?a) 0)
    ((+ ?a ?b) (+ ?b ?a))
    ((+ (+ ?a ?b) ?c) (+ ?a (+ ?b ?c)))
    ((+ ?a (+ ?b ?c)) (+ (+ ?a ?b) ?c))
    ((+ ?a 0) ?a))

  ;; Cost = 1 per symbol.
  (define-analysis (ast-size :merge #'min :bottom +inf-cost+ :type cost)
    ((?f ?x ?y) (+ 1 (ast-size ?x) (ast-size ?y)))
    ((?f ?x) (+ 1 (ast-size ?x)))
    ((?f) 1))
#+END_SRC

Solve an instance with stochastic term rewriting:
#+BEGIN_SRC
GGS-USER> (stochastic-search '(+ (+ (- x) (+ y (- x))) (+ (- y) x)) 'cancel 'ast-size
                             :max-time 1 :verbose t)

#+END_SRC
